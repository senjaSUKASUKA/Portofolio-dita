Dedikasi Pada Pembelajaran Rekayasa Perangkat Lunak

Saya adalah siswa program keahlian Pengembangan Perangkat Lunak dan Gim (PPLG) di SMK Negeri 2 Surakarta. Sejak mengawali pendidikan kejuruan, ketertarikan saya tertuju pada bagaimana baris-baris kode dapat menyelesaikan permasalahan nyata, merapikan birokrasi informasi, serta menyuguhkan pengalaman interaktif yang menyenangkan bagi pengguna.

Di sekolah, saya terbiasa mendalami logika komputasi terstruktur, pola perancangan Object-Oriented Programming (OOP), serta kolaborasi proyek menggunakan version control system. Saya memandang setiap tugas dan tantangan pemrograman sebagai ruang riset untuk mengasah ketepatan sintaks, efisiensi algoritma, dan estetika antarmuka.
